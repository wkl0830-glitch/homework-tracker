🌟 真雲端（Supabase）— 換電腦自動同步（推薦）

照下方 3 步驟建立免費雲端，完成後兩台電腦打開同網址就會自動同步，不用再手動匯入。

① 到 supabase.com ↗ 建專案 → ② Table Editor 建表 homework_data（id=text, data=jsonb）→ ③ SQL Editor 貼上 RLS 設定（見下方）→ ④ Settings → API 複製 URL 與 anon key 貼到下方 → ⑤ 按「註冊」建老師帳號並登入
點開看建表 SQL（通關密碼模式，只需執行一次） 
create table if not exists homework_data (
  id text primary key,
  data jsonb,
  updated_at timestamp default now()
);
insert into homework_data (id, data) values ('main', '{}'::jsonb) on conflict (id) do nothing;
-- 通關密碼模式：用 app 層保護，資料表開放 anon 讀寫（簡單）
alter table homework_data disable row level security;
-- 若想改成「只有登入者可改」，再啟用下面：
-- alter table homework_data enable row level security;
-- create policy "allow_authenticated" on homework_data for all using (auth.role()='authenticated') with check (auth.role()='authenticated');
方式一：分享連結（免設定）

按「產生分享連結」，把連結傳到另一台電腦打開，就會自動還原最新資料。

小提醒：連結包含目前全部資料，請只傳給信任的老師。
方式二：同步碼（適合口頭傳達）

設定一組同步碼，另一台電腦輸入同樣同步碼就能載入（僅同一瀏覽器可用）。

🔑 通關密碼

主密碼（老師）有全部權限；小老師密碼只能登記作業（可新增、打勾、備註），不能改名單、刪作業、改密碼或雲端設定。

✅ 已解鎖：
已設過？小老師密碼可單獨更新，留空主密碼只改小老師。
密碼會同步到雲端，新裝置輸入任一組即可解鎖（權限不同）。忘記主密碼需在已解鎖的老師裝置上清除重設。
